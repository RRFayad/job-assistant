# AI suggestions require explicit human confirmation before changing stored data

As AI-assisted editing surfaces multiply — Track Changes on Tailored Resumes/Cover Letters ([0004](./0004-track-changes-default-for-tailored-documents.md)), and now a section-scoped "Ask AI" assistant while editing the Profile itself — each one could independently choose whether to apply its suggestions directly or require review. We decided none of them do: regardless of which surface produces it, an AI suggestion is always presented as a proposed change the Candidate must explicitly accept before it touches their actual stored data. This generalizes what Track Changes already established for documents and what Grounding ([0005](./0005-grounding-principle-fetched-sources-only.md)) already established for factual accuracy into one standing product principle: AI assists, the Candidate stays in control of what actually gets saved.
