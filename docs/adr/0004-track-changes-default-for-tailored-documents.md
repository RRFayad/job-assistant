# AI-tailored documents default to Track Changes, not a clean final version

The Tailored Resume and Tailored Cover Letter are AI edits of an existing Profile document. We deliver them as Word files with Track Changes enabled by default, with an explicit option for the Candidate to request a clean/final version instead. Reviewability of exactly what the AI changed was prioritized over the added technical cost of generating tracked-changes DOCX output — the Candidate should never have to blindly trust an AI-edited version of their own resume or cover letter.
